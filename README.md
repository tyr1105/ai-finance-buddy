# AI财经助手 - 财报速读

一键AI分析财经新闻：智能摘要、情绪分析、关键指标提取、投资视角
面向中国3亿散户投资者的Chrome浏览器扩展

## 产品定位

在东方财富、新浪财经、雪球等网站上，一键让AI帮你分析任何财经新闻。

目标用户：中国A股/港股散户投资者

核心痛点：
- 财经新闻太多看不过来
- 专业术语散户看不懂
- 分不清利好/利空
- 缺少客观判断工具

## 商业模式

Freemium模型：
- 免费版：每天5次分析
- Pro版：9.9元/月，无限次+强模型+历史+导出
- 团队版：29.9元/月

预期收入：月1-2获客 -> 月3-4转化 -> 月7-12达2万/月 -> 年2达10万/月

毛利率>85%（DeepSeek API约0.001元/次分析）

## 支持网站

东方财富、新浪财经、雪球、同花顺、财联社、华尔街见闻、财新、第一财经、证券时报

## 安装

1. Chrome -> chrome://extensions/ -> 开发者模式
2. 加载已解压的扩展程序 -> 选择本项目文件夹
3. 设置中配置DeepSeek API Key
