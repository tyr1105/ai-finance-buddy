# 隐私政策 / Privacy Policy

**最后更新日期 / Last Updated:** 2026年5月

---

## 中文版

### 概述

"AI财经助手 - 财报速读"（以下简称"本扩展"）是一款浏览器扩展程序，旨在帮助用户利用人工智能技术快速分析财经新闻与财报信息。我们高度重视您的隐私，本政策旨在说明本扩展在数据收集、使用和保护方面的做法。

### 1. 数据收集

**本扩展不收集任何个人用户数据。**

具体而言：
- **不收集**个人身份信息（如姓名、邮箱、电话号码等）
- **不收集**浏览历史、Cookie 或任何追踪数据
- **不收集**用户行为分析数据
- **不嵌入**任何广告SDK或第三方追踪代码
- **不使用**任何远程服务器存储用户数据

本扩展仅在用户本地浏览器中使用 `chrome.storage` API 存储以下信息：
- 用户自行配置的 API 密钥（加密存储于本地）
- 用户的使用历史记录（分析过的文章列表及结果）
- 用户偏好设置（如语言、模型选择等）

以上所有数据均存储在用户本地浏览器中，不会以任何形式上传或传输至我们的服务器。

### 2. API 调用说明

本扩展通过调用人工智能服务提供商（如 DeepSeek、OpenAI 等）的 API 来实现核心分析功能。相关说明如下：

- **API 密钥由用户自行提供：** 本扩展不提供、不存储、不分发任何 API 密钥。用户需自行在相应 AI 服务商处注册并获取 API 密钥，并在扩展设置中自行填写。
- **直连 AI 服务商：** 所有 API 请求均由用户浏览器直接发送至用户所选择的 AI 服务提供商的 API 端点，不经过任何中间服务器或代理。
- **传输内容仅为分析所需：** 发送至 API 的内容仅限于用户当前选择分析的财经新闻/财报文本及必要的提示词（prompt），不包含其他任何数据。
- **数据处理受 AI 服务商条款约束：** 发送至 AI 服务商的数据受该服务商自身的隐私政策和服务条款约束，建议用户查阅相关服务商的隐私政策。

### 3. 第三方共享

**本扩展不与任何第三方共享用户数据。**

- 我们不运营任何后端服务器，因此不存在数据上传或转储的可能
- 我们不出售、交易或以其他方式向任何第三方传输用户信息
- 本扩展不集成任何第三方分析工具（如 Google Analytics）
- 本扩展不包含任何广告组件或推广内容

### 4. 儿童隐私保护（COPPA 合规声明）

本扩展遵守《儿童在线隐私保护法》（COPPA）相关规定：

- 本扩展不针对13岁以下儿童设计，也不有意收集13岁以下儿童的个人信息
- 本扩展不收集任何年龄段的个人身份信息
- 由于本扩展不收集任何个人数据，因此不存在收集、使用或披露儿童个人信息的情况
- 家长或监护人可随时通过清除浏览器本地存储数据来删除扩展的所有本地数据

### 5. 数据安全

- API 密钥及本地数据存储在浏览器的 `chrome.storage` 本地存储空间中，受浏览器自身安全机制保护
- 所有 API 通信均通过 HTTPS 加密传输
- 建议用户妥善保管自己的 API 密钥，避免在不受信任的环境中使用本扩展

### 6. 用户权利与数据控制

用户对自己的数据拥有完全控制权：
- **查看：** 用户可随时在扩展中查看本地存储的分析历史
- **删除：** 用户可通过扩展内功能或清除浏览器数据来删除所有本地存储信息
- **导出：** 用户可自行导出本地存储的分析记录

### 7. 政策更新

我们可能会不时更新本隐私政策。更新后的政策将在本页面发布，并通过扩展更新说明告知用户。继续使用本扩展即表示您同意遵守更新后的隐私政策。

### 8. 联系方式

如您对本隐私政策有任何疑问或建议，请通过以下方式联系我们：

- Chrome Web Store 扩展页面中的"支持"选项
- GitHub Issues（如适用）
