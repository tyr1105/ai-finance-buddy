## 2. Detailed Description（详细描述）

### 🚀 一键AI解读，让每篇财经新闻都变成投资决策

**AI财经助手 - 财报速读** 是一款专为中文投资者打造的Chrome浏览器扩展。无论你在哪个财经平台阅读新闻，只需一键点击，AI即刻为你生成深度分析报告——新闻摘要、情绪判断、核心要点、关联个股（含利好/利空标签）、投资视角、风险提示，一应俱全。

告别逐字阅读长篇财报和新闻的日子。AI帮你读完、读懂、读透，让你在投资决策中快人一步。


### ✨ 核心功能

**🧠 智能AI分析**
- 一键生成完整的财经新闻分析报告
- 自动提取新闻摘要与核心要点
- AI情绪判断：利好/中性/利空一目了然
- 投资视角解读，帮你快速形成判断

**📈 关联个股追踪**
- 自动识别新闻中涉及的A股及港股标的
- 利好/利空标签直观展示，关联个股涨跌心中有数
- 帮你快速判断新闻对持仓的影响

**🌐 9大财经平台全面覆盖**
- 东方财富、新浪财经、雪球、同花顺
- 财联社、华尔街见闻、财新
- 第一财经、证券时报
- 你常看的，我们都支持

**⌨️ 效率至上**
- 快捷键 `Ctrl+Shift+A` 随时唤起分析，无需鼠标操作
- 浮窗设计，不离开当前页面，阅读分析两不误

**📝 历史与导出**
- 自动保存分析历史，随时回看
- 一键复制分析报告，方便分享交流
- 支持导出为Markdown格式，便于整理归档

**🔑 自带API密钥，数据安全**
- 支持使用你自己的 DeepSeek / OpenAI API Key
- 数据直接在你的浏览器与AI服务之间传输，不经第三方服务器
- 你的阅读习惯和投资偏好完全私密
