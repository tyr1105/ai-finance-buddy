常见问题

FAQ

AI财经助手是如何工作的？▼

AI财经助手通过 DeepSeek 大语言模型分析网页上的财经文章内容。当你点击扩展图标时，它会提取当前页面的文章文本，发送给 AI 模型进行分析，并在数秒内返回结构化的分析结果，包括情绪判断、关联个股、投资视角和风险提示。

我的数据安全吗？▼

绝对安全。AI财经助手采用"自带密钥"模式——你使用自己的 DeepSeek API Key，所有数据仅在你的浏览器与 DeepSeek API 之间传输。我们不会收集、存储或处理任何分析数据。扩展代码开源透明，可随时审查。

如何获取 DeepSeek API Key？▼

访问 DeepSeek 官方平台（platform.deepseek.com），注册账号后在 API 管理页面创建密钥。DeepSeek 提供免费额度，新用户即可开始使用。每次分析成本仅约 ¥0.001，非常经济实惠。

免费版和 Pro 版有什么区别？▼

免费版每天可使用 5 次 AI 分析，适合偶尔查看的投资者。Pro 版（¥9.9/月）提供无限次分析、历史分析记录和优先技术支持，适合每天需要阅读大量财经资讯的活跃投资者和交易员。

支持哪些浏览器和网站？▼

目前支持 Chrome 浏览器（包括 Edge、Brave 等 Chromium 内核浏览器）。支持东方财富、新浪财经、雪球、同花顺、腾讯财经、网易财经、证券时报、第一财经、和讯等 9 大主流财经平台，并持续增加中。

分析结果准确吗？可以做为投资建议吗？▼

AI 分析基于大语言模型对文本的理解，能够高效提炼信息和判断情绪倾向，但仅供参考和学习使用。AI 分析结果不构成任何投资建议，投资决策请结合多方信息并自行判断风险。股市有风险，投资需谨慎。
